# VM

## Build

```
cmake -S . -B build
cmake --build build
```

## Run

```
./build/vm
```

## Commiting

```
clang-format -i src/*/*.cpp src/*/*.h src/*.cpp
```

# Структура виртуальной машины

Виртуальная машина имеет регистровую архитектуру. Программа содержит список
инструкций и таблицу констант. Поддерживаемые команды и формат инструкций
описаны в `isa.md`

## Значения и регистры

Значение может иметь тип `int` (64-битное целое), `float` (`double`) или
`nil`. Регистры хранятся в массиве из 65 536 значений и адресуются
относительно базы текущего кадра вызова

## Выполнение

Счётчик команд `pc` содержит индекс следующей инструкции. Интерпретатор
последовательно выполняет инструкции; переходы и вызовы функций изменяют
`pc`. Для вызовов используется отдельный стек кадров, в котором сохраняются
адрес возврата и база предыдущего кадра

## Память

Код и константы хранятся в отдельных списках. В проекте также есть класс кучи,
но команды работы с ней пока не подключены к интерпретатору
