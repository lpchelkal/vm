# ISA виртуальной машины

Виртуальная машина имеет регистровую архитектуру. Значения в регистрах могут иметь тип `int`, `float` или `nil`. Программа состоит из инструкций и таблицы констант

Каждая инструкция занимает 32 бита: код операции - 8 бит, `A` - 8 бит, затем либо `B` и `C` по 8 бит, либо `D` - 16 бит. `sD` - поле `D`, интерпретированное как знаковое число. `R[A]` - регистр `A` текущего кадра

| Команда | Поля | Действие |
|---|---|---|
| `STP` | - | Останавливает программу |
| `MV` | `A`, `B` | Копирует `R[B]` в `R[A]` |
| `LI` | `A`, `sD` | Записывает целое значение `sD` в `R[A]` |
| `LF` | `A`, `sD` | Записывает `sD` в `R[A]` как `float` |
| `LK` | `A`, `D` | Загружает в `R[A]` константу с индексом `D` |
| `JMP` | `D` | Переходит к инструкции с индексом `D` |
| `JZ` | `A`, `D` | Переходит к `D`, если `R[A] == 0` |
| `JNZ` | `A`, `D` | Переходит к `D`, если `R[A] != 0` |
| `ADD` | `A`, `B`, `C` | Целочисленное сложение: `R[A] = R[B] + R[C]` |
| `SUB` | `A`, `B`, `C` | Целочисленное вычитание: `R[A] = R[B] - R[C]` |
| `MUL` | `A`, `B`, `C` | Целочисленное умножение: `R[A] = R[B] * R[C]` |
| `DIV` | `A`, `B`, `C` | Целочисленное деление: `R[A] = R[B] / R[C]` |
| `MOD` | `A`, `B`, `C` | Остаток от деления: `R[A] = R[B] % R[C]` |
| `NEG` | `A`, `B` | Меняет знак целого числа: `R[A] = -R[B]` |
| `FADD` | `A`, `B`, `C` | Дробное сложение чисел `float`: `R[A] = R[B] + R[C]` |
| `FSUB` | `A`, `B`, `C` | Дробное вычитание чисел `float`: `R[A] = R[B] - R[C]` |
| `FMUL` | `A`, `B`, `C` | Дробное умножение чисел `float`: `R[A] = R[B] * R[C]` |
| `FDIV` | `A`, `B`, `C` |  Дробное деление чисел `float`: `R[A] = R[B] / R[C]` |
| `FNEG` | `A`, `B` | Меняет знак дробного числа `float`: `R[A] = -R[B]` |
| `I2F` | `A`, `B` | Преобразует `R[B]` из `int` в `float` и записывает в `R[A]` |
| `F2I` | `A`, `B` | Преобразует `R[B]` из `float` в `int` и записывает в `R[A]`. Дробная часть отбрасывается |
| `EQ` | `A`, `B`, `C` | Проверяет равенство целых чисел: `R[B] == R[C]` |
| `LT` | `A`, `B`, `C` | Проверяет, что целое `R[B] < R[C]` |
| `LE` | `A`, `B`, `C` | Проверяет, что целое `R[B] <= R[C]` |
| `FEQ` | `A`, `B`, `C` | Проверяет равенство дробных чисел: `R[B] == R[C]` |
| `FLT` | `A`, `B`, `C` | Проверяет, что дробное `R[B] < R[C]` |
| `FLE` | `A`, `B`, `C` | Проверяет, что дробное `R[B] <= R[C]` |
| `IN` | `A` | Считывает целое число в `R[A]` |
| `FIN` | `A` | Считывает дробное число в `R[A]` |
| `PR` | `A` | Выводит `R[A]` с переводом строки |
| `CALL` | `A`, `D` | Сохраняет адрес возврата и базу, сдвигает базу на `A` и переходит к инструкции `D` |
| `RET` | `A` | Возвращает `R[A]` вызывающему коду и восстанавливает его кадр. Если кадра вызова нет, останавливает программу |
| `ALLOC` | Не определены | Выделение памяти **Не реализована** |
| `FREE` | Не определены | Освобождение памяти **Не реализована** |
| `LOAD64` | Не определены | Загрузка 64-битного значения из памяти **Не реализована** |
| `STORE64` | Не определены | Запись 64-битного значения в память **Не реализована** |

Команды сравнения записывают в `R[A]` целое `1`, если условие истинно, иначе `0`. Условные переходы проверяют регистр типа `int`. При ошибке типа, недопустимом индексе или выполнении нереализованной команды машина сообщает об ошибке
